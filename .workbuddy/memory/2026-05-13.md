## 关键技术教训

- JS文件中文引号("")与ASCII双引号(")冲突导致语法错误
- 解决方案: 全局替换中文引号为书名号「」，避免与外层JS字符串分隔符冲突
- 净版JS脚本由Python生成(gen_v3.py)，确保无语法问题
- 运行命令: `unset NODE_OPTIONS && NODE_PATH=... node build_product_manual_v3.js`
